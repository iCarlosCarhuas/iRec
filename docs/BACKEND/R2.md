# Cloudflare R2 — BYO Storage

## Flujo de conexión

El usuario proporciona:
- Account ID;
- bucket;
- Access Key ID;
- Secret Access Key.

Backend:
1. cifra secretos;
2. construye endpoint S3 compatible;
3. prueba permisos mínimos;
4. guarda conexión si es válida.

## Upload

1. PWA solicita `presign-upload`;
2. API autoriza usuario/álbum;
3. API crea object key controlado;
4. API devuelve URL prefirmada de corta duración;
5. navegador sube directo a R2;
6. PWA confirma finalización;
7. backend valida metadata y registra asset.

## Namespace

```text
albums/{albumId}/originals/{assetId}.{ext}
albums/{albumId}/derived/{assetId}/thumb.webp
albums/{albumId}/themes/{themeId}/...
```

El cliente nunca define libremente el prefijo final.

## CORS

El asistente de configuración debe guiar al creador para permitir únicamente los orígenes necesarios.
