# iRec v0.3.0 — Album Core

`v0.3.0` convierte la base de identidad de iRec en una primera aplicación
utilizable de álbumes.

## Incluido

- creación y edición de álbumes;
- visibilidad pública/privada;
- propietario y membresías;
- invitación y aceptación de miembros;
- propuestas de contenido;
- moderación owner-only;
- UI Angular para Album Core;
- vista pública anónima de solo lectura;
- aislamiento de álbum privado/no existente;
- migraciones aditivas de álbumes, membresías y propuestas;
- baseline de Data Safety para PostgreSQL;
- gates AD-1 a AD-7.

## Fuera de este release

Se mantienen para releases posteriores:

- carga de fotos y Cloudflare R2;
- generación temática con IA;
- YouTube uploads;
- YouTube Live / WebRTC -> RTMPS;
- hardening final de producción.

## Release flow

1. `scripts/release/prepare-v030.mjs`
2. `scripts/release/verify-v030.ps1`
3. Runtime/E2E gate de `V0.3.0-E2E.md`
4. commit de preparación de release
5. merge a `integration/v0.3.0`
6. gate final sobre integración
7. merge de integración a `main`
8. tag anotado `v0.3.0`
9. push de `main` y del tag

El tag no debe crearse si el E2E final todavía tiene un caso pendiente.
